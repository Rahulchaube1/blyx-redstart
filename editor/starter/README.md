# Redstart starter

Update a binary-event model and report uncertainty in its probability.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Redstart** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
0.5
0.05
2
2
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/redstart) · [View the release](https://github.com/Rahulchaube1/blyx-redstart/releases/tag/v0.1.0)
